Musik Latar — Upload Langsung

Firebase terhubung: upload musik otomatis menjadi URL publik di Firebase Storage.

Pilih file musik pada menu 11, lalu tekan Simpan Musik. File diunggah ke Firebase Storage dan tautannya otomatis tersertakan ke link undangan — bisa diputar tamu di perangkat mana pun.

Belum isi konfigurasi Firebase di atas? Upload tetap jalan sebagai cadangan lokal.

File disimpan di IndexedDB browser ini dan dapat digunakan kembali selama membuka dari perangkat/browser yang sama, namun tamu di perangkat lain belum bisa mendengarnya sampai Firebase dihubungkan.

Konfigurasi Firebase (Cloud Sync & Storage)

Tempel object firebaseConfig dari Firebase Console (Project Settings > General > Your apps) dalam format JSON. Wajib memuat apiKey, projectId, appId, dan storageBucket. Setelah tersimpan, RSVP akan sinkron ke Firestore secara realtime dan upload musik akan menghasilkan URL publik lewat Firebase Storage.

Pastikan Firestore Database, Authentication (Anonymous), dan Storage sudah diaktifkan di Firebase Console sebelum menghubungkan, dan atur Security Rules agar data tamu tidak terbuka untuk dibaca publik.
